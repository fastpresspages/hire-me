03 · How I work

Four rules I keep
when nobody is watching.

  1. 01

    Ship the smallest useful thing.

    A working audit beats a roadmap for an audit platform. Then improve the thing people already use.

  2. 02

    Measure, don’t invent.

    If there is no source, it does not go on the page. Dated snapshots are honest; rounded-up claims are not.

  3. 03

    Write the docs.

    The README is part of the product. If a stranger cannot run it, it is not finished.

  4. 04

    Leave a receipt.

    Source, tests, reports, changelog. Trust is easier when the work is inspectable.
